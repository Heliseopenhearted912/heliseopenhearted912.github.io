🚀 Getting Started

Getting tweet-radar up and running on your Windows computer takes less than 5 minutes. Here's exactly what you need to do:

  1. Visit the download page: Go to this link using your browser (Chrome or Edge recommended).
  2. Find the download button: On the page, look for a green button labeled "Code" or a section called "Releases". Click on it.
  3. Download the extension file: You'll see options to download. Choose the file that ends with .zip (for example: tweet-radar-v1.0.zip). Click it to download.
  4. Extract the ZIP file: Windows will show the downloaded file at the bottom of your browser. Right-click on it and select "Extract All...". Choose a folder you'll remember, like C:\tweet-radar.
  5. Open your browser's extensions page: In Chrome, click the three-dot menu (⋮) in the top-right corner, then go to More Tools → Extensions.
  6. Enable Developer Mode: In the top-right of the Extensions page, toggle "Developer mode" to ON.
  7. Load the extension: Click the "Load unpacked" button that appears, then select the folder where you extracted the ZIP file (the one containing a file named manifest.json).
  8. Done! You should see the tweet-radar icon appear in your toolbar. Click it to open the settings panel.
✅ Success! If you followed the steps above, tweet-radar is now installed. If you get stuck or don't see the icon, check the Troubleshooting section below.

📖 How to Use tweet-radar

After installation, the fun begins! Here's a quick walkthrough:

🎛️ Setting Your Rules

Click the tweet-radar icon in your browser toolbar. A small panel will appear. This is your control center.

  • + Add Rule: Click this to create a new rule. For example, type show posts about artificial intelligence.
  • Import Rules: Use the blue button to load pre-made rule sets from the community, such as "Tech News" or "Minimalist Feed".
  • Priority slider: Adjust how strict the AI should be. Low priority shows more posts; high priority shows only top gems.

👀 Reading Your Radar

When you visit X (Twitter) after setting rules, tweet-radar adds little score badges next to each post, like [92] or [34]. The higher the number, the more relevant it is to your rules. You can also click the radar icon to see a filtered view—only posts with a score above your chosen threshold.

Not happy with a result? Fine-tune your rules directly from the panel. The AI learns and adjusts instantly.

🛠️ Troubleshooting Common Issues

❓ My browser says "Extensions cannot be installed from this site"

Don't worry, that's normal. Since you're loading the extension manually, you must enable Developer Mode first (Step 6 above). Ensure the folder you extracted contains the manifest.json file. If you see an error about a "manifest file is missing or unreadable," double-check your extraction folder.

❓ I don't see any score badges on X

Make sure you've reloaded your X tab after installing the extension (press Ctrl + R). Also, open the tweet-radar panel and confirm you have at least one rule set up. If the problem persists, close and reopen your browser completely.

❓ The extension icon is greyed out

This usually means the extension can't run on the current page. It works on x.com and twitter.com. Open your X feed, and the icon should activate.
